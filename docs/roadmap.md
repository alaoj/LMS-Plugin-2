# Zadora LMS Development Roadmap

## MVP

MVP proves the core commercial learning loop:

- Authentication and custom frontend login.
- User management and role-aware dashboard access.
- Courses, lessons, statuses, and catalog display.
- Enrollments and learner progress.
- Certificates, templates, manual issue, wallet, and public verification.
- Payments through Stripe and Paystack.
- Basic reporting dashboards.
- In-app notifications.

Why: these features allow training providers and corporate teams to sell, assign, deliver, complete, certify, and track training without wp-admin.

## V1

V1 deepens operational maturity:

- Course builder polish.
- Assessments and instructor grading.
- Corporate departments and seat management.
- Report exports to CSV, Excel, and PDF.
- Email notification templates.
- Gutenberg blocks and shortcodes.
- Certificate drag-and-drop builder.
- AI quiz/objective/grading workflows with usage limits.
- Offline service worker and branded offline screen.

Why: V1 completes the PRD’s core workflow set while keeping the product maintainable after MVP validation.

## V2

V2 expands channels and analytics:

- WhatsApp notifications.
- Flutterwave gateway.
- Advanced analytics snapshots and trend reports.
- Mobile app API hardening.
- More granular automation rules.

Why: these are valuable but should sit on proven notification, payment, reporting, and API foundations.

## V3

V3 turns the platform into an ecosystem:

- SaaS multi-tenant architecture.
- White labeling.
- Marketplace.
- Public developer SDK.
- Expanded public API and scoped API clients.

Why: these features require stable domain boundaries, tenancy ownership, and developer contracts established in earlier releases.
